# DUST PROTOCOL — HVH Edition

Браузерный 2D top-down HvH-шутер по мотивам CS:GO / de_dust2. Один файл — `index.html`, чистый HTML5/CSS/JS (Canvas API, без внешних зависимостей). Открывается двойным кликом в любом современном браузере.

## Настройка матча
Перед стартом (и в каждой фазе закупки — **без таймера**, старт по кнопке «В БОЙ» или Enter) выбираются:
- **Режим**: Зачистка или **Закладка бомбы** — плент C4 на A/B (удерживать E), таймер 40с, CT сбегаются снимать (урон сбивает снятие); победа — взрыв или зачистка, поражение — дефьюз/смерть/таймаут
- **Число врагов** (1–8) и **тимейтов** (0–4) — союзные боты воюют на вашей стороне (зелёные, с метками)
- **Стартовая сложность** (Новобранец → Элита)

## Умный ИИ
Боты не бегут тупо в пуш: по плану они занимают **кемп-споты и ван-веи** (окно CT, за mid doors, pit, за машиной на long, ниндзя на B…), держат угол с приседом, при перезарядке и между очередями **отходят за укрытие**, а при потере цели садятся в **засаду** на споте рядом с вами — пушат только агрессивные тиры. В режиме бомбы CT обороняют пленты.

## HVH: боты тоже читеры
В HVH-режиме (включён по умолчанию) боты играют с полным набором читов, как и вы:
- **Wallhack** — всегда знают, где вы, и давят через всю карту
- **Snap-aimbot + hit chance** — мгновенный доворот с настраиваемой точностью по тирам
- **Anti-aim / desync** — модель бота стоит боком к своей реальной позиции (фейк-хитбокс)
- **Spinbot** — видимая модель бешено крутится
- **Resolver** — на каждую очередь решают, вскрыть ли вашу анти-аим
- **Double tap** — элитные боты досылают второй патрон

Побеждает тот, чей resolver и anti-aim работают лучше.

## Чит-меню (Insert) — в стиле gamesense/skeet
Тёмное перетаскиваемое окно с радужной полосой, вертикальными вкладками и групбоксами:
- **RAGE** — Aimbot (silent, FOV, hit chance, min damage, autofire, target selection), Auto wall (пробитие стен), Resolver, Double tap, **Backtrack** (стрельба по истории хитбоксов), Auto stop, Hitbox (auto/head/body safe), Safe point
- **ANTI-AIM** — yaw (backward/jitter/spin), spin speed, desync amount, **Hide shots** (on-shot AA); фейковая модель рисуется пунктиром
- **LEGIT** — плавный aimbot (FOV/smooth), RCS, триггербот с задержкой реакции
- **VISUALS** — ESP (corner/full box, name, HP, weapon, distance, glow, resolved-хитбокс), radar hack, sound ESP, offscreen arrows, weapon drops, **damage numbers**, **grenade prediction** (траектория и радиус), backtrack-точки
- **MISC** — watermark с **анимированным clantag**, динамический keybind list, event log, hitmarker/hit sound/kill sound, прицел + spread circle, auto pistol, **auto buy**
- **SKINS** — цвет/паттерн модели игрока и оружия
- **CONFIG** — 3 слота пресетов (alpha/beta/gamma) + reset; всё автосохраняется в localStorage

## Бинды (как в ските) — настраиваются в MISC → Keybinds
Любую клавишу можно переназначить кликом (клик по кнопке → нажать новую клавишу):
- **X** (держать) — fake duck: хитбокс приседа при полной видимой модели
- **V** (держать) — auto peek: точка возврата, после выстрела затягивает обратно за укрытие
- **C** (держать) — форс minimum damage = 1
- **M** — полноэкранный обзор карты (позиции команды, врагов по правилам радара, бомбы)
- **F / T** — тоггл rage / anti-aim на лету
- **Insert** — меню чита

## Карта — de_dust2 по радару CS:GO
Планировка перенесена с оверлея de_dust2: B-плент слева-сверху (плита, машина, ниндзя), B doors → CT mid, CT spawn по центру, mid с **узкими деревянными mid doors и окном CT** (ван-вей), xbox у входа на катвок, catwalk → short → A, A-плент с гусём/дефолтом/машиной, CT ramp, **long A** с машиной наверху, синим контейнером, **long doors** и питом, suicide из T в мид, туннели с поворотом (верхние/нижние). Узкие однотайловые проёмы дверей — как в CS. **Радар как в CS**: тёмный квадрат с центром на игроке, буквы плентов A/B, точки команды/врагов, маркер бомбы. A* навигация ботов.

**Прострелы и ван-веи:**
- Деревянные двери (mid doors, long doors, двери B↔CT) простреливаются любым оружием — классический AWP-банг через mid doors работает
- Окно CT↔верх мида: видно и стреляется насквозь, пройти нельзя — ван-вей для AWP
- У каждого оружия своя пробивная способность (AWP пробивает ящики и тонкие стены), урон падает по прочности поверхности
- **Боты тоже простреливают**: потеряв вас из виду за дверью/ящиком, банят по свежей позиции

## Остальное
- 8 видов оружия + 3 гранаты, меню закупки без таймера (клавиши 1–5); в HVH-режиме — $16000 каждый раунд, как на HvH-серверах
- Резолвер общий для rage и legit: триггербот и легит-аим тоже вскрывают desync ботов; без silent aim прицел видимо снапается на цель
- Раундовая структура: закупка → бой → итоги → рост сложности; 3 жизни
- Пробитие стен (auto wall) со штрафом урона по прочности поверхности
- Синтезированный звук (Web Audio API), частицы, hitmarker, kill/hit sounds
- Стабильные 60 FPS, фиксированный шаг симуляции

## Управление
WASD — движение · мышь — прицел · ЛКМ — огонь · ПКМ — прицеливание · Shift — тихий шаг · Ctrl — присед · R — перезарядка · 1–4 — слоты · G — смена гранаты · E — подобрать оружие · B — закупка · **Insert — чит-меню**
