# DUST PROTOCOL

Браузерный 2D top-down шутер в стиле CS:GO против ботов. Один файл — `index.html`, чистый HTML5/CSS/JS (Canvas API, без внешних зависимостей). Открывается двойным кликом в любом современном браузере.

## Возможности
- Раундовая структура: закупка (15с) → бой → итоги → рост сложности; 3 жизни на матч
- Карта по мотивам de_dust2 (два «сайта», mid, long, туннели), тайловая сетка + A* навигация ботов
- 8 видов оружия с балансом (урон/скорострельность/разброс/дальность/цена) + 3 типа гранат
- Экономика: деньги за убийства и раунды, меню закупки с категориями (клавиши 1–5)
- Боты с конечным автоматом: Patrol → Alert → Combat → Search → Flee, 4 уровня сложности, LOS-рейкасты, слух
- HUD: здоровье/броня/патроны/деньги, таймер, миникарта, килфид, кастомизируемый прицел
- Меню ассистентов (Insert): Aimbot, ESP, радар-хак, triggerbot, анти-эйм, скины — всё в localStorage
- Синтезированный звук через Web Audio API, частицы (вспышки, гильзы, дым, пробоины)

## Управление
WASD — движение · мышь — прицел · ЛКМ — огонь · ПКМ — прицеливание · Shift — тихий шаг · Ctrl — присед · R — перезарядка · 1–4 — слоты · G — смена гранаты · E — подобрать оружие · B — закупка · Insert — ассисты
